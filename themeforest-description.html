Orbit Overseas – Recruitment Management System

Manage candidate recruitment and overseas employment processing from one connected workspace. Orbit Overseas is a full-stack recruitment and office operations application for manpower agencies, overseas employment consultants, and recruitment teams. It brings candidate intake, lead follow-up, interview coordination, destination-country processing, document tracking, payment collection, agent management, and employer demands into one role-based system.

Orbit Overseas is provided as an installable application with its source code, server-side functionality, database schema, and starter data. Built with Next.js 16, React 19, TypeScript, MySQL, and Prisma ORM, it gives developers a working foundation they can configure and extend for their own recruitment operations.

Recruitment & Operations Modules

  • Dashboard: See recruitment activity and operational summaries in a central workspace.
  • Candidate Management: Create candidate records and maintain contact details, passport information, profession, destination preferences, and related processing files.
  • Lead Follow-Up: Record calls and follow-up activity to help office teams keep track of prospective candidates.
  • Country Processing: Organize candidate files by destination and move them through country-specific stages. Saudi Arabia, Dubai/UAE, and other-country workflows are supported, with country and stage configuration available in the application.
  • Registration & Interviews: Manage interview schedules, candidate rosters, attendance, and assessment information.
  • Documents: Attach files to candidate processing records and track document verification and status.
  • Payments: Record candidate payment transactions and installments, follow payment status, and prepare printable money receipts.
  • Works & Demands: Maintain employer and recruitment demand information for operational tracking.
  • Agent Management: Maintain agent profiles and associate agents with candidate referrals and processing workflows.
  • Reports & Data: Review supported operational reports and use available CSV import and export tools.
  • Tutorials: Organize internal tutorial and training resources.

Role-Based Workspaces

Orbit Overseas includes separate access experiences for administration, office operations, and agent partners. Role and module permissions control which parts of the application a user can access. Administrators can manage user access and configure operational permissions for their organization.

Security & File Storage

  • Password hashing and signed user sessions.
  • Role- and permission-aware access to application features.
  • Private file storage using the local storage driver, with an S3-compatible storage option.
  • Activity and audit records for operational oversight.
  • Optional Cloudflare Turnstile configuration for the login flow.

Technology Stack

  • Framework: Next.js 16 App Router
  • Frontend: React 19 and TypeScript
  • Database: MySQL 8+ or MariaDB 10.5+
  • ORM: Prisma
  • Validation: Zod
  • Authentication: Signed sessions and bcrypt password hashing
  • Storage: Private local storage or S3-compatible storage
  • Utilities: CSV workflows and PDF generation

Installation Overview

  1. Install the project dependencies.
  2. Configure the database connection and authentication secret in the environment file.
  3. Generate the Prisma client and initialize the database schema.
  4. Run the seed script to create starter records and demo accounts.
  5. Start the application and sign in with one of the seeded accounts.

The included README.md contains the complete installation commands and environment configuration details.

Important Information

  • This is a self-hosted full-stack application and requires a configured MySQL or MariaDB database.
  • The live demo is provided for product evaluation. The delivered package includes source code; it is not a hosted SaaS subscription.
  • Third-party integrations, hosting, and external services must be configured with your own accounts and credentials where applicable.
  • Before production deployment, set a unique authentication secret, configure private file storage, create your own users, and replace or disable demo credentials.
